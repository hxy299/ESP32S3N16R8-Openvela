# src/platform/ — 平台抽象层（BSP）

把「板子相关」的细节关在这一层里，让 `app/` 和 `protocol/` 与具体硬件解耦。
换板子（比如以后换 ESP32-C6）只改这一层。

## 计划中的模块

| 文件 | 职责 | 依赖的硬件事实 |
| --- | --- | --- |
| `bsp_gpio.c/.h` | GPIO 初始化与读写封装 | NuttX `/dev/gpio*` 或 `esp32s3_gpio` |
| `bsp_relay.c/.h` | 继电器/灯控输出，含上电默认态与安全互锁 | 继电器模块所接引脚（**待确认**） |
| `bsp_rgb.c/.h` | 板载 WS2812B 状态指示 | **GPIO48**，单总线，需 WS2812 焊盘短接 |
| `bsp_board.h` | 板级常量集中定义（引脚号、有效电平） | 见 [`../../docs/hardware/`](../../docs/hardware/README.md) |

## 引脚使用约束（务必遵守）

- **GPIO26–GPIO32 绝对不可用**：被板载 Flash/PSRAM（N16R8 的 OPI PSRAM）占用，未引出。
- **GPIO43/GPIO44**：UART0 调试串口，占用中。
- **GPIO19/GPIO20**：原生 USB-OTG，若启用 USB 设备/主机则不可复用。
- **GPIO0 / GPIO45 / GPIO46**：Strapping 引脚，上电瞬间电平影响启动模式，
  用作输出需谨慎（GPIO0 还是 BOOT 按键）。
- 推荐用于继电器输出的候选引脚：GPIO1–GPIO18、GPIO21、GPIO47、GPIO48（RGB 除外）。

> ⚠️ 上述「推荐候选」是依据引出的 GPIO 范围推断，**具体接哪一路需用户确认继电器接线**，
> 确认后写入 `bsp_board.h` 并在此表登记。

## RGB 状态灯约定（建议）

| 颜色/效果 | 含义 |
| --- | --- |
| 蓝色常亮 | 系统启动完成，BLE 广播中 |
| 绿色常亮 | 已被 A7Z 连接 |
| 绿色闪一次 | 收到开灯命令 |
| 熄灭闪一次 | 收到关灯命令 |
| 红色慢闪 | 已断开 / 异常 |

> ⚠️ 此为建议约定，待用户确认。
