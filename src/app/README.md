# src/app/ — 业务应用层

智能家居灯控的业务逻辑，与蓝牙协议栈解耦。

## 计划中的职责

| 模块 | 职责 |
| --- | --- |
| 应用初始化 | 启动时初始化平台层、注册 GATT 服务、进入事件循环 |
| 灯控状态机 | 维护每路灯的开/关状态、来源（本地按键/BLE 远程）、超时 |
| 命令分发 | 收到 `protocol/` 解析出的命令，分发到具体灯控动作 |
| 事件上报 | 状态变化时通过 BLE Notify 主动上报给 A7Z |
| 心跳/看门狗 | 周期性心跳，掉线检测 |

## 待用户确认后细化

- 灯的路数（1 路 / 多路）
- 是否需要本地物理按键（板载 BOOT 键 GPIO0 可复用）
- 掉电后是否恢复上次状态
- 是否要延时/定时/调光（PWM）

这些未确认前，本目录只保留 README，不写死任何假设。
