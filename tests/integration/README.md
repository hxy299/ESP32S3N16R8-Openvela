# tests/integration/ — 集成测试

验证多个模块协同工作，可在 PC（逻辑仿真）或 NuttX 模拟器（`sim` 配置）上运行。

## 计划场景

| 编号 | 场景 | 期望 |
| --- | --- | --- |
| IT-01 | 收到合法「开灯」报文 | 状态机置为 ON，并产生一条「状态上报」报文 |
| IT-02 | 收到重复「开灯」报文 | 状态不变，不产生冗余上报（或按约定上报） |
| IT-03 | 收到非法长度报文 | 状态不变，返回错误码，不崩溃 |
| IT-04 | 平台层写入失败 | 状态回滚，上报错误状态 |
| IT-05 | BLE 断开 | 状态保持，重连后主动上报当前状态 |

## 与实机测试的分工

集成测试只验证**逻辑正确性**，不验证**电气正确性**（灯到底亮没亮）。
电气部分放 [`../hardware/`](../hardware/README.md)。
