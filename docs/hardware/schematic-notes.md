## 1. 逐块解读

| 电路块 | 关键器件 | 连接关系 | 备注 |
| --- | --- | --- | --- |
| **主控** | U3 = **ESP32-S3-WROOM-1-N16R8** | 3V3 供电；R7 = 10 kΩ（EN 上拉）；C7 / C8 = 100 nF | 模组型号由此确认 |
| **USB-ISP（Type-C）** | USB2 = Type-C 16PIN；D3 = B5819W SL 肖特基；R22 / R23 = 5.1 kΩ（CC1 / CC2） | VBUS → 板上 5V；经 B5819W 供 VBUS | **该 USB 口未接 ESP32 的 D+/D−**，数据只走 CH340 |
| **USB 转 TTL** | U2 = **CH340C**；C1 / C4 = 100 nF；C2 = 10 µF（V3 去耦） | U2.TXD → **GPIO44 (U0RXD)**；U2.RXD → **GPIO43 (U0TXD)**；U2.DTR → R5(10 kΩ) → DTR；U2.RTS → R6(10 kΩ) → RTS | 串口调试 + 自动下载 |
| **自动下载电路** | D1 / D2 = **SS8050** NPN 三极管 | DTR / RTS 交叉驱动 EN(CHIP_PU) 与 GPIO0 | 这就是「板载 ISP 一键下载电路」，无需手动按键 |
| **USB-OTG（Type-C）** | USB1 = Type-C 16PIN；R15 / R17 = 5.1 kΩ；D11、I4 | 直连 **GPIO20 (D+)** 与 **GPIO19 (D−)** | 原生 USB，**未接 CH340** |
| **5V 稳压** | U12 = **南麟 LN2220**（丝印 VUOT）；C2 / C3 = 10 µF | 升压产生板上 5V 轨 | 供给 WS2812 与 5V 排针 |
| **3.3V 稳压** | U11 = 丝印 **TAR**（具体型号原理图未标）；C1 = 10 µF | 5V → 3V3 | 板上 3V3 轨 |
| **电源指示** | R25 = 1 kΩ + **LED3**（0603 红） | 接 5V 轨 | **不可控**（商家所述「电源灯」） |
| **串口指示灯** | R1 / R2 = 470 Ω；D6 / D7 = **KT-0603R** 红 | LED1 接 **GPIO43 (U0TXD)**；LED2 接 **GPIO44 (U0RXD)** | 收发数据时闪烁 |
| **板载 RGB** | U1 = **WS2812B** | 5V 供电；DIN ← **GPIO48** | 单总线寻址灯 |
| **按键** | K1 = **EN**；K2 = **SW4 (BOOT)**；R18 = 10 kΩ；R19 = 10 kΩ；C9 / C10 = 100 nF | BOOT 按键 → **GPIO0**；EN 按键 → CHIP_PU；按键另一脚接 GND | — |
| **GPIO3 跳线** | J5 = 2 脚；R19 = 10 kΩ | **GPIO3 → J5 引脚 1**；R19 从 GPIO3 下拉到 GND | 见 §3 |
| **扩展排针** | J1 / J2 = X6511WV-22H-C30D00 | J1 出 3V3 / GPIO1–GPIO4 / …；J2 出 U0TXD / U0RXD / … | 22 + 22 pin |

## 2. 与商家网页资料的不一致之处

| 项 | 商家网页资料 | **原理图（权威）** | 结论 |
| --- | --- | --- | --- |
| 三颗 LED | 「电源灯（不可控）+ TX/RX 灯」 | 电源灯接 5V 轨（R25 + LED3）；TX/RX 分别接 GPIO43 / GPIO44 | ✅ 一致 |
| 3V3 输出电流 | 「最大约 1 A」 | U11 具体型号原理图未标注（仅丝印 `TAR`） | ⚠️ **无法从原理图核实 1 A**；按商家说法使用但需留余量 |
| GPIO19 / GPIO20 | 同时被推荐给 UART2、I2C、USB | 硬件上是**原生 USB D−/D+**，且**未接 CH340** | ✅ 原理图支持「保留给 USB」的结论 |
| GPIO3 | 「GPIO3 焊盘」，无说明文字 | 经 R19 10 kΩ 下拉，接 J5 | 见 §3 |
| UART1 引脚 | 网页说 GPIO17/18「建议使用」 | 原理图未直接标 UART1；引脚复用总图上 GPIO17=`U1TXD`、GPIO18=`U1RXD`（经 GPIO 矩阵），而硬件默认 UART1 脚是 GPIO19/20 | ✅ 采用 GPIO17/18，但**需实测确认** |

## 3. GPIO3 跳线（J5）—— 电气事实清楚，**用途待确认**

原理图确认的电气关系：

```
GPIO3 ──┬── R19 = 10 kΩ ── GND     （下拉）
        └── J5 引脚 1
            J5 引脚 2 ── GND
```

即：**GPIO3 平时被 10 kΩ 下拉为低电平。** 用短路帽短接 J5，只是把 GPIO3
再与 GND 连一次（同一网络），**短接前后电平不变**。

由此推断：

- 它**不像** WS2812 那种「使能焊盘」——WS2812 焊盘短接会**改变拓扑**（接通使能），
  而 J5 短接的是**已存在的 GND 网络**，不改变任何电气行为。
- 可能是：预留的外部按键/开关接口（外接开关到 GND 即可触发）、预留测试点、
  或原理图丝印编号与实物位置需要进一步核对。

> ⚠️ **本项目不猜测它的用途，也不使用 GPIO3。**
> 需用户在实物上确认 J5 位置与设计意图后再决定。

## 4. 由此得出的引脚使用约束

| GPIO | 状态 | 原因 |
| --- | --- | --- |
| GPIO26–GPIO32 | ❌ **绝对不可用** | 模组内部接 Flash / OPI PSRAM，未引出 |
| GPIO43 / GPIO44 | ❌ 已占用 | UART0 调试串口，接 CH340C + TX/RX 指示灯 |
| GPIO19 / GPIO20 | ⚠️ 保留 | 原生 USB D− / D+，用 USB 时不可复用 |
| GPIO48 | ⚠️ 保留 | 板载 WS2812B 数据线 |
| GPIO0 | ⚠️ 谨慎 | Strapping + BOOT 按键 |
| GPIO45 / GPIO46 | ⚠️ 谨慎 | Strapping 引脚 |
| GPIO3 | ⚠️ 暂不使用 | 用途待确认（见 §3） |
| 其余（GPIO1、2、4–18、21、47 等） | ✅ 可用 | 已引出到 J1 / J2 排针 |
