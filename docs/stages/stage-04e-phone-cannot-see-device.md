## 二、★ 我的测试方法错误（必须承认）

**我一直在用"Windows 能看到"当作"手机也能看到"的代理。**
这个假设**不成立** —— 两者的扫描行为、过滤器、缓存机制都不同。

我之前多次基于 Windows 的结果下结论（"广播正常"），
但这些结论**不能推出手机也能看到**。

## 三、诊断中的发现

### 3.1 广播参数正常

读 `bt_hcicore.c:2145-2151`，NuttX 设置的广播参数：

```c
memset(set_param, 0, sizeof(*set_param));
set_param->min_interval = BT_HOST2LE16(300);   /* 187.5 ms */
set_param->max_interval = BT_HOST2LE16(300);
set_param->type         = type;                /* BT_LE_ADV_IND = 可连接非定向 */
set_param->channel_map  = 0x07;                /* 37/38/39 三个信道全开 */
```

**全部正常** —— 间隔标准、三信道全开、类型可连接。

### 3.2 我们的广播数据有长度字段错误

`btsh_light_main.c:500-503`：

```c
g_scan_rsp[0].len  = 1 + strlen(CONFIG_BTSH_LIGHT_ADV_NAME);   /* = 11 */
g_scan_rsp[0].type = BT_EIR_NAME_COMPLETE;
memcpy(g_scan_rsp[0].data, CONFIG_BTSH_LIGHT_ADV_NAME,
       strlen(CONFIG_BTSH_LIGHT_ADV_NAME));                    /* 只拷 10 字节 */
```

**声明长度 11，实际只拷贝 10 字节。**

对比 `btsak`（正确写法）：

```c
sd[1].len  = sizeof("btsak");          /* sizeof 含 '\0' = 6 */
strlcpy(sd[1].data, "btsak", ...);     /* strlcpy 会拷 '\0' */
```

**两者语义不同**：`strlen` 不含终止符，`sizeof` 含。
我用 `1 + strlen()` 补了长度，但 `memcpy` 用的是 `strlen()`，少拷了终止符
（那 1 字节是未初始化数据）。

> ⚠️ 这是**真实缺陷**，需要修。但它**不太可能是手机找不到的主因**
> （Windows 能正常解析出完整名字，说明长度字段至少没破坏整个 AD 链）。

### 3.3 ★★ 最有价值的线索：地址类型

对比两次连接记录：

| 时机 | 连接事件里的对端地址类型 |
| --- | --- |
| **手机成功连接时**（`HT-11`，CCC 修复后） | `le_conn_complete: status 0 handle 1 role 1 7C:53:C7:63:31:64 **(random)**` |
| **现在的广播** | 使用**公共地址** `e0:72:a1:f2:8f:ea` |

**手机成功连接的那次，对端是 `(random)` 随机地址。**

而当前固件广播时 `own_address_type = 0`（公共地址，见
`bt_hcicore.c` 里 `memset(set_param, 0, ...)` —— 该字段未显式设置，默认为 0）。

> 📌 **推测**：手机的蓝牙栈可能对"公共地址 + 无服务 UUID"的设备
> 有过滤或缓存行为。但这需要验证，**不能当结论**。

## 四、如何区分"手机问题"与"板子问题"

**关键测试：用手机的蓝牙设置（系统级扫描），而不是 nRF Connect。**

| 结果 | 含义 | 下一步 |
| --- | --- | --- |
| 系统蓝牙能看到 `BTSH-LIGHT` | 手机 BLE 扫描正常；问题在 **nRF Connect 的过滤/缓存** | 清理 nRF Connect 缓存，或换 LightBlue / BLE Scanner 试 |
| 系统蓝牙也看不到 | 手机确实收不到这块板子 | 检查手机蓝牙开关、距离、是否有其他 BLE 中心设备干扰 |

**同时需要确认**：
1. 手机蓝牙是否**已开启**
2. 手机与板子距离（板子 RSSI 约 −20，应很近）
3. nRF Connect 是否开了**过滤器**（如"只显示有名字的设备"）
