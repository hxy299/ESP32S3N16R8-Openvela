# docs/ — 文档中心

本目录存放 `OpenvelaESP-BTSH` 项目的全部技术文档。文档语言为中文。

## 子目录说明

| 目录 | 用途 | 何时更新 |
| --- | --- | --- |
| [`stages/`](stages/README.md) | **分阶段开发记录（核心）**。每个阶段一份 md，记录目标、动作、命令、结论、遗留问题 | 每完成一个阶段**必须**更新 |
| [`hardware/`](hardware/README.md) | 硬件事实：引脚定义、原理图解读、供电与注意事项 | 拿到新硬件资料时 |
| [`protocol/`](protocol/README.md) | 蓝牙 GATT 接口契约：服务/特征 UUID、报文格式、状态机 | 协议一旦变更 |
| [`bringup/`](bringup/README.md) | 板级适配（board port）技术笔记：Kconfig、defconfig、启动链路、踩坑 | 适配过程中持续追加 |

## 文档约定

1. **一处事实，一处记录**：硬件引脚值只写在 `hardware/`，别处引用链接。
2. **命令可复现**：记录中出现的每条命令都要能直接复制执行，注明执行目录（WSL 路径）。
3. **区分「已验证」与「推测」**：推测内容必须显式标注 `> ⚠️ 未验证`。
4. **不猜**：凡是无法从资料或实测确认的信息，写进「待确认」并同步提问，不要凭空填数。
5. 文件名全小写，用连字符分隔，例如 `stage-02-board-port.md`。
