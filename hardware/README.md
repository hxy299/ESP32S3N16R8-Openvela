# hardware/ — 硬件工程文件

存放与本项目相关的硬件设计与接线资料。

## 计划收录

| 文件 | 内容 | 状态 |
| --- | --- | --- |
| `wiring/` | 接线图：ESP32-S3 ↔ 继电器模块 ↔ 灯具 | ⏳ 待用户确认硬件后绘制 |
| `schematic/` | 原厂原理图（从商家资料页附件获取） | ⏳ **需用户下载** |
| `datasheet/` | 关键器件数据手册 | ⏳ |
| `photos/` | 实物照片（与 `assets/images/` 分工：此处放工程视角的接线/焊接照片） | ⏳ |

## 与 `assets/` 的分工

| | `hardware/` | `assets/` |
| --- | --- | --- |
| 内容 | 工程文件：原理图、接线图、器件手册、焊接记录 | 展示资源：标注图、截图、演示图 |
| 读者 | 要动手接线/改板的人 | 要理解项目的人 |

## 待确认的硬件信息（阻塞接线设计）

1. 继电器/灯控模块的**型号**与**有效电平**（高电平触发 or 低电平触发）
2. 模块的**供电电压**与**电流**（5 V？3.3 V 能否直接驱动？）
3. 被控灯具的**电压/功率**（220 V 交流？低压直流？**涉及强电，安全第一**）
4. 模块与开发板之间是否需要光耦/三极管隔离
5. 通道数量（1 路 / 多路）

> ⚠️ **安全警告**：若控制 220 V 交流灯具，必须使用带光耦隔离的继电器模块、
> 强弱电分开走线、外壳绝缘，并确保断电后接线。本项目在文档层面会明确标注风险点，
> 但**不替代合格的电气安全措施**。
